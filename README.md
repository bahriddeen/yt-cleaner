## About
YouTube Cleaner is a powerful, customizable browser extension designed to help you regain control over your YouTube experience. By removing distractions and clutter, it ensures a focused and clean interface tailored precisely to your preferences.

Whether you want to eliminate the endless scrolling of YouTube Shorts, hide comments, or just clean up the navigation sidebar, YouTube Cleaner has you covered with a simple toggle interface.

## Key Features
- **Block YouTube Shorts**: Completely hides Shorts from your home feed, search results, subscriptions, and sidebars.
- **Hide Distractions**: Quickly hide comments, related video recommendations, and other visually noisy elements.
- **Clean UI**: Streamlines YouTube so you solely interact with the content you want to see.
- **Easy Toggle Menu**: A sleek popup menu lets you enable or disable filters instantly without needing to reload.

## Installation

Since the extension is currently in beta/development, you can install it manually by loading it as an unpacked extension:

1. Clone this repository to your computer:
   ```bash
   git clone https://github.com/bahriddeen/yt-cleaner.git
   ```
2. Open your Chromium-based browser (Chrome, Brave, Edge, etc.) and go to the extensions page:
   - `chrome://extensions/` (or equivalent)
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click on **Load unpacked** and select the folder of the cloned repository.
5. Head over to YouTube, click the brain icon in your extensions toolbar, and customize your experience!
